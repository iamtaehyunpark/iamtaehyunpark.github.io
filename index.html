Research

In progress, Yonsei University, since June 2026

Finds which step of a failed multi-agent run went wrong by ranking every step’s uncertainty, with no extra training.

Python, LLM observer models, Who&When benchmark

When several AI agents work together and the job fails, someone has to work out which step actually broke it. Reading the whole transcript with a very large model is expensive, and training a dedicated model needs many labelled failures.

SURF uses a small model that scores each step by how likely it is to be fine, and keeps that score instead of rounding it to yes or no. A step rated 51% and one rated 91% both round to “yes” but are very different. Ranking the steps by score points to the shakiest one, with no training and no labelled failures.

  • Tested on Who&When, a public set of failed multi-agent runs where humans marked the culprit step.
  • Compared on accuracy and cost against methods that need a large judge model or extra training.
  • Experiments are still running, so no results are quoted yet.

Active, University of Wisconsin–Madison, June to August 2026

A separate “inspector” model scores every step an AI agent takes, so a bad step can be flagged before it does damage.

Python, vLLM, ALFWorld, HotpotQA

An AI agent finishes a task in many small steps: look something up, click a button, run a command. Sometimes step 6 quietly goes wrong and everything after it is wasted. The goal is a warning light that comes on before a bad step is taken.

The obvious approach is to ask the agent how sure it is, but what “sure” means changes from one model to the next. Instead, a separate, fixed model acts as an inspector. It watches each step of any agent and gives it a trust score, like a second pair of eyes that doesn’t share the agent’s blind spots.

  • Evaluated on 62,065 steps from agents doing household tasks in a text world (ALFWorld) and answering multi-part questions (HotpotQA).
  • Caught mistakes better than the agents’ own self-checks in 9 of 11 settings, at about 1/100 the cost of using GPT-4o as the judge.
  • Chooses when to raise the alarm for a new agent without any labelled mistakes from that agent.
  • Negative results are reported alongside the positive ones.

Code and results

Completed, University of Wisconsin–Madison, spring 2026

Long-term memory for an AI assistant, kept as one organised document that the assistant edits as it learns.

Python, FastAPI, React

Chat assistants forget. The usual fix, retrieval, chops knowledge into separate snippets and searches them, which loses how ideas relate. EngramTrace works more like a well-kept notebook: everything the assistant knows lives in one organised web document with chapters and sections. As conversations come in, the assistant files new facts in the right place, removes what is out of date, and, after a long idle stretch, tidies the whole notebook, a bit like sleep does for us.

  • Because it is one document, the assistant sees the whole structure at once and places new knowledge in a fixed number of model calls.
  • A note is found partly by where it sits: each carries some of the meaning of the headings above it, so the same sentence means different things under “Login” and “Data formats”.
  • The memory opens in any browser, so a person can read and correct it.
  • Tested on all 2,417 questions of MuSiQue, a hard multi-step question benchmark, feeding every passage through the live memory first: 0.646 answer F1 and 0.515 exact match, using open models on a single GPU. Comparisons with plain retrieval baselines are still to come.

Save tiny moments as they happen, a line, a photo, a place, a voice note. Shape them into events, blog entries and pinboards later, or never.

Swift and SwiftUI, Next.js, Supabase

Most journaling asks you to write something worth publishing before it saves anything, so most small moments never get saved: a sentence you thought on a walk, a photo that caught a mood, the café you stepped into. Fethr turns that around: record first, shape it later. Pieces land on one private timeline with no title and no form. Weeks later you can group them into an event, start a blog entry from them, or arrange them on a pinboard.

  • Private by default. The timeline has no likes, comments or audience. Only what you deliberately write or broadcast reaches anyone.
  • No blank page. Select moments from your timeline and they become the first draft of a blog entry.
  • A pinboard like a room you decorate. Move, resize and rotate photos, text and stickers, and share a link with a guestbook and a soundtrack.
  • Share a day, not a feed. A broadcast lets close friends walk through your day for 24 hours, then it disappears.
  • Works offline, has Home Screen widgets, and speaks English and Korean.
  • Native iPhone app and web app on one backend, with over 2,300 automated tests.

Run commands and edit files on a remote server from your own machine, for you or for an AI coding agent. 29 releases, installs with Homebrew.

Go, FUSE, SSH

Working on a GPU server usually means logging in over SSH, copying files back and forth, and babysitting long training runs. Live Git fixes the three worst parts, so the server feels like part of your laptop.

  • Run anything there. Type lg before a command and it runs on the server with live output, colours, progress bars and Ctrl-C, exactly as if it were local.
  • Edit here. lg mount makes the server’s project appear as a normal folder, instantly, even for huge ones. Files download when opened, and saves reach the server in milliseconds.
  • Leave long runs alone. lg run -d detaches a job so it keeps going when your laptop sleeps or the connection drops.

Made for AI agents too. A coding agent can’t answer a two-factor login prompt or live inside a remote shell. Live Git gives it real local files to read and edit, and one command to run things on the server. lg init writes an instruction file so the agent knows how to use it from its first prompt, so the loop of fix, retrain and read the results can run without a person in the middle.
